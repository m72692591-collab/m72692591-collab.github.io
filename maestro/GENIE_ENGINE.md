# MAESTRO GENIE ENGINE — стадия 1 (26.10.2026)

Модуль для публичного сайта Maestro Business. Добавлен в `maestro/index.html` отдельными файлами `assets/maestro-genie.css` и `assets/maestro-genie.js`. **Это работающая по коду базовая интеграция, но не проверенный в облачном браузере релиз и не полноценная LLM-система.**

## Что реализовано

- Вызываемый из меню и плавающей кнопки персонаж с CSS/SVG-анимацией появления, свечением, мимикой в момент речи.
- Текстовые вопросы, локальная база сценарных ответов по направлениям услуг.
- Подсказки по популярным услугам, передача темы в существующую форму заявки.
- Опциональное голосовое озвучивание через браузерный SpeechSynthesis (после нажатия кнопки).
- Опциональная диктовка через Web Speech API, где это доступно. Важно: некоторые браузеры отправляют аудио на собственный облачный сервис. Перед использованием сообщать посетителю; для строго локального распознавания требуется отдельный движок.
- Адаптация для мобильных экранов, клавиатурное закрытие Escape, reduced-motion, никакие ключи не используются.

## Ограничения

- Здесь **нет подключенной генеративной ИИ-модели**. Сценарные ответы нельзя называть «живой нейросетью».
- Здесь **нет клонированного голоса владельца**. Браузерный русский голос зависит от ОС и браузера.
- Эта версия **не отправляет заявки на сервер**: продолжает работу существующей формы с ручным копированием подготовленной заявки. Перед реальным автоприемом потребуется защищённый бекенд/CRM, проверка согласий и защита от спама.
- Анимированный персонаж пока SVG/CSS, не VRM-3D и не фотореалистичный цифровой двойник.
- GitHub Pages обслуживает статические файлы, не запускает модель синтеза/LLM сам по себе.
- В репозитории нельзя хранить закрытые голосовые образцы, API-ключи и личные переписки клиентов.

## Подключение собственного голоса владельца

В `maestro-genie.js` уже предусмотрен адаптер `window.MAESTRO_GENIE_VOICE` с методами:

```js
window.MAESTRO_GENIE_VOICE = {
  async speak(text) {
    // Клиент делает запрос к собственному защищенному TTS-бекенду.
    // Воспроизвести полученный аудиопоток и дождаться завершения.
    // Никаких секретов в браузерном коде.
  },
  stop() {
    // Остановить воспроизведение.
  }
};
```

Эта часть **пока интерфейс подключения, а не реализованный сервер/голосовой клон**. Для клонирования владелец должен добровольно передать аудиозапись и явно разрешить использование голоса для цифрового консультанта. Не публиковать её в GitHub или публичной папке сайта.

Рекомендованный формат записи: 3–10 минут естественной русской речи без музыки и посторонних разговоров; WAV предпочтительнее, MP3 допустим. Лучше несколько спокойных и эмоциональных фрагментов с чётким произношением. Исходники и модель голосового профиля должны храниться закрыто; предусмотреть отзыв разрешения/удаление.

Движок выбирать после проверки качества русской речи и лицензии **как кода, так и весов**: OpenVoice V2 распространяется под MIT, но не имеет нативного русского TTS; необходим совместимый русский базовый синтезатор. F5-TTS: лицензия базовых весов CC BY-NC ограничивает коммерческое использование. Возможный кандидат — CosyVoice, но русский сценарий требуется испытать. Само программное обеспечение может быть бесплатным; облачное исполнение требует вычислительных ресурсов.

## MAESTRO LAB — смежный продукт в той же ветке

Добавлена отдельная страница `maestro-lab.html`, доступная из главного экрана сайта и отдельного раздела-приглашения. В ней 3 локальные сценарные симуляции (ИИ-оператор, CRM, HR), пошаговая шкала работы, калькулятор ручных операций с прозрачной формулой, копирование расчёта и переход к заявке с сохранением выбранного направления.

Это **не настоящий ИИ**, не серверная CRM, не гарантированный расчёт экономии. Все демонстрационные данные вымышлены. После тестов этот продукт можно последовательно заменить настоящими защищёнными интеграциями.

### Запись голоса (Android)

Записать 3–7 минут естественной речи на расстоянии ~15–20 см от телефона, немного сбоку от микрофона в тихой комнате. Форматы WAV, M4A, MP3 допустимы, присылать как исходный файл в приватную переписку. Не коммитить запись в GitHub и не публиковать. Для zero-shot в TTS можно позже вырезать качественные фрагменты 5–15 секунд с транскриптом.

Кандидат TTS: Fun-CosyVoice 3 (заявлена поддержка русского и zero-shot клонирования, веса Apache-2.0). Несмотря на заявления, качество русской речи нужно проверить на фактическом образце: независимое тестирование пока не доказывает его стабильность. Ресурсы на постоянную генерацию речи не входят в бесплатный GitHub Pages.

**Критичный пункт:** существующая форма сайта пока только копирует заявку в буфер обмена и не доставляет её компании. Нельзя утверждать, что заявка принята. Для реальной коммерческой воронки необходимо подключение серверной доставки до перевода демо в production.
