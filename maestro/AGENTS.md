# Instructions for AI assistants working in maestro/

This directory is the customer-facing MAESTRO BUSINESS site. Follow
[SITE_FACTORY_STANDARD.md](SITE_FACTORY_STANDARD.md) for new sites, site improvements and
commercial website requests. The eight-stage flow is a delivery standard, not an
instruction to re-generate previously approved work.

- **Inspect first:** read the existing file, connected services and open PRs before editing.
  Preserve existing functional behavior and owner's approved brand choices.
- **Use real facts only:** no fabricated clients, testimonials, metrics, prices, credentials
  or claims of successful integrations. Label prototypes and simulations.
- **Language:** natural professional Russian; avoid literal machine translations,
  generic motivational slogans and phrases that make no sense in context.
- **Mobile-first:** support small screens, slow connectivity, keyboard navigation,
  reduced-motion preferences and a usable non-3D experience.
- **Security/privacy:** never put access tokens or personal data into public source.
  No server submission, payment, or publication claims without an actual tested receiver
  and permission to use it.
- **Delivery:** implement in a separate branch when collaborating, preserve active PRs,
  run the Node structural check suites; when Chromium is available, run Playwright suites.
- **Truthful report:** list what changed, what tests were run and passed, what was not
  checked, and blockers. Do not state that a PR is live or deployed until verified.
- **Commercial boundaries:** paid operations and account authorization require
  explicit permission. Do not imply conversion or search-engine ranking guarantees.
