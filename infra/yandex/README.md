# МАЭСТРО — подготовка размещения

Перенесено на актуальный `main` из PR #2 (облачный фундамент) и PR #11 (защита контекста сборки); ничего не развёрнуто и не оплачено.

Комплект `infra/runtime/`: Nginx (только `127.0.0.1:8082`), PHP-FPM, внутренний MySQL, закрытые файлы секретов, безопасный статический пакет `tools/package_maestro.py`. На текущем GitHub Pages форма по-прежнему формирует заявку вручную. В контейнерном пакете обработчик включается только при явной сборке с утверждённым HTTPS origin.

До запуска: подтверждённый сервер/тариф и согласие на расходы, HTTPS reverse proxy и реальный IP, уведомление владельцу, согласия и срок хранения данных, резервные копии с проверкой восстановления, тесты на синтетических данных, без переключения DNS.

`docker compose down -v` допускается только для одноразового CI-окружения, никогда для реальной базы. Исторический зелёный CI PR #2 не доказывает готовность нового PR.
