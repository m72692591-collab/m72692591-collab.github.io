# Два основных проекта: МАЭСТРО и Анима Тактус
Обновление по прямому указанию владельца от 26.10.2026. Этот документ заменяет прежний план очередности запуска. История прежних расчётов сохранена в Git.

## Активный состав
1. **МАЭСТРО** — консультант, сайт, рабочие обращения, общая логика существующего бота, собственный тиражируемый продукт.
2. **Анима Тактус** — доработка существующего Flutter-приложения, безопасный перенос, письменная саморефлексия и авторские материалы. Не создавать параллельный заменяющий продукт.

## Позже, без текущего запуска
- Праксельта ремонт: ограниченный пилот после завершения основного рабочего пути двух проектов.
- ВахтаФакт: следующий этап, после сверки актуальных исходников и экономики внешних источников данных.

«Инженер с нуля» исключён из текущего перечня разработки, переноса и бюджета. Это не распоряжение удалить действующие сайты, репозитории, платежи или материалы.

## Разделение данных
Общие технические решения можно переиспользовать. Личные записи Анимы нельзя объединять с CRM МАЭСТРО, рекламой, продажами, журналами содержимого или общей базой знаний. Ни один посетитель сайта не получает полномочия бота Авито. Диалоги мессенджеров и веб-сеансы изолированы.

## Последовательность переноса
1. Проверить точный проект Amvera: URL, репозиторий, HTTP-интерфейс, тариф и ресурсы. Адаптер без действующего endpoint не считается подключением.
2. Собрать и протестировать версии обоих проектов без обращения к реальным клиентским данным.
3. Для Анимы сохранить прежний адрес/идентичность приложения на переходный период. Для текущего защищённого черновика подготовлен явный зашифрованный экспорт/восстановление; это не перенос всей истории и не облачная синхронизация.
4. Проверить доступ к Яндексу, бюджет, сервисы гранта и фактический срок. Не активировать грант преждевременно.
5. Размещать по одному сервису: тестовый адрес, HTTPS, контрольный маршрут, восстановление/откат. Не выключать старую систему до проверки новой.

## Конструкция первого этапа
МАЭСТРО: сайт → защищённый API бота → проверенный каталог → черновик ТЗ → отдельное подтверждение сохранения обращения. Сценарный резерв при недоступности ИИ.

Анима: существующее приложение с локальными записями → отдельный статический контейнер/адрес для веб-версии. Нет автоматической отправки дневника или записи на сервер. Android/iOS остаются самостоятельными сборками; не подменять production-подпись отладочной. Авторская программа «Назад в своё Я» добавляется только из подтверждённых материалов, без выдуманной структуры/цены/лечебных обещаний.

## Расходы и пределы
Предыдущая таблица была сценарной оценкой, не счётом и не разрешённым бюджетом. Для двух проектов пока не установлены действующая оплата Amvera, конфигурация Яндекса, объём пользователей и покрытие гранта. Нельзя объявлять фиксированную стоимость миграции до проверки этих параметров.

Базовый подход сохраняется: существующие ресурсы прежде новых покупок; без Kubernetes, постоянного GPU и нескольких управляемых кластеров БД на первом пилоте. Одна небольшая VM — возможный экономный пилот, но не гарантия отказоустойчивости или любой нагрузки. Резервное восстановление проверяется отдельно.

Формула затрат: текущая Amvera + фактические вычисления/диск/IP/резервные копии + измеренные токены/речь + согласованный резерв. Пользовательская запись голоса нужна только для персонального голоса, а не для всех работ.

Сами бюджетные уведомления не являются жёсткой остановкой расхода. В приложении нужны ограничения запросов, длины контекста, параллельности, тайм-аутов и повторов. Грант не вычитается из расчёта, пока его покрытие не подтверждено.

## Не объявлять выполненным без подтверждения
- Настоящий Amvera endpoint, активный приём обращений, оплаченные ресурсы/грант и перенос DNS не настроены в этом изменении.
- Голосовой клон и генеративный ИИ не подключены.
- Файлы в GitHub и контейнерный пакет не доказывают завершённую миграцию на рабочий сервер.
- Для Анимы нужны тесты физического телефона, новая сборка с прежней подписью и проверка переноса конкретного хранилища.

## Критерии ближайшего результата
МАЭСТРО: контрольная заявка реально записана, повтор не создаёт дубль, владелец видит обращение, уведомление подтверждено.
Анима: исходный полезный маршрут сохранён, личные данные не утекли, копия открывается только верным паролем, новая версия проверена на целевой платформе.
